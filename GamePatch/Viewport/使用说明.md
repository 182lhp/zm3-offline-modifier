# 窗口与装备提示修复

运行 `python patch_tooltips.py 原游戏.swf 输出.swf`。仅向 ShowObj、PetShowObj 的 showattribute 尾部插入边界处理，原有指令和其他方法保持；不改奖励、身份、活动、存档及装备数值。

提示框按其在舞台中的实际包围框检查940×590逻辑边界，留4像素内边距；必要时缩小超大提示，通过父容器坐标变换移动，兼容容器偏移与缩放。普通角色装备和宠物装备各验证3个边缘位置。

启动器改动由 build_launcher38.py 以 Python3.8 marshal 修改两个模式常量及默认模板完成，所有 Python 操作码保持。运行前在工作目录提供当前启动程序内的 starter.marshal；输出 starter-patched.marshal。按原 PyInstaller archive 格式替换 starter 成员即可，其他成员、PE及图标保持。新模式 exact-fit、force-scale、letterbox off；默认设置为缩放1（940×590），过大的初始尺寸继续自动限制在屏幕内。

窗口强行exact-fit方案已被../WindowAspect替代；当前应构建窗口宽高联动组件，不再发布exact-fit。
