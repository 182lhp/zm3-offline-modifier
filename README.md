## 当前实现

当前已验证的本地技术基线是 **2.34.0**，并非已经创建的 GitHub Release。

- Windows x64 上的 C# / WPF 修改器，目标框架为 .NET 8。
- 角色与背包、图鉴、宠物、技能、药园、土地庙、增益、会员和本地点券管理。
- 具备存档身份、防重回执、容量检查和中断恢复的本地礼包流程。
- C# 与 Python 共用的存档事务，以及同源、带摘要校验的规则库。
- 本目录游戏进程识别、关联诊断日志和资源版本检查。
- 构建、测试、源码包验证、安装回滚演练与安装后验证的统一入口。

本地基线已通过 76 项 Python 回归、WPF 全流程、实际冻结服务和复制游戏验证。完整测试依赖配套资料，不能直接等同于公共 CI 已通过。

## 构建说明

完整本地流程使用 Python 3.10+、.NET 8 SDK、PowerShell 7，以及经声明和校验的配套游戏、冻结宿主、图片和规则资料。

公共源码的独立构建入口为 `./build.ps1`，会运行范围检查、规则验证、76 项单元测试和 WPF 编译，不读取个人存档。完整配套维护入口为：

```powershell
./release.ps1 -GameRoot 'D:\Games\ZM3'
./release.ps1 -GameRoot 'D:\Games\ZM3' -Install
```

示例路径需要替换为本机目录。上述命令用于具备完整配套输入的维护环境；公共源码可通过 `build.ps1` 编译修改器；完整游戏集成验证仍需配套安装及未随仓库发布的专用集成夹具。
