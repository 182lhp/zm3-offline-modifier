## 统一规则与统一发布（2.34.0）

修改器与本地礼包后台使用同一份 `schema/game_rules.json`。宠物成长、形态与技能条件、装备参考和强化、角色参考、VIP、药园、土地庙、增益、背包容量及原版宠物礼包范围均由统一规则库提供。数值和领取行为保持当前版本。旧 schema 保留兼容，但不再由这两个程序分别拼接规则或自行补上缺项。

「高级工具 → 资源版本」同时显示规则版本和指纹。程序与规则不匹配时会停止读取；不要单独复制旧规则文件。旧安装包缺少统一规则时，修改器使用同一份编译内嵌规则兼容读取。

源码的 `Rules/definitions.json` 与经过 SHA256 固定的 `Rules/Inputs` 是规则编辑来源；`Build/generate_rules.py` 统一生成部署数据、修改器嵌入资源及后台版本标识。生成文件不手工修改。规则来源、补齐的精灵记录和对应游戏哈希均可追溯。

源码根目录提供 `release.ps1`。执行 `./release.ps1 -GameRoot "游戏主目录"` 会构建并验证发布包；加 `-Install` 后在验证全部通过时安装到原路径。流程包含规则生成、修改器构建、回归测试、真实后台及复制游戏验证、资源清单、精简源码包重建验证、安装中断回滚演练和安装后校验。`-Resume -Install` 仅接受源码指纹、输入资源、测试报告和发布文件仍完全匹配的已验证产物。失败时保留报告并停止，不略过失败项。

Flash 游戏及冻结宿主沿用经过 SHA256 固定的配套二进制输入；本轮没有重编或修改游戏本体。历史 Flash/窗口补丁源码变更而二进制输入未更新时，发布流程会拒绝继续。无需为了日常修改器更新重复重建旧补丁。

启动名称、快捷方式、存档、礼包领取记录和设置保持不变。测试仅使用复制目录；正式目录不接收测试存档、测试兑换码、QA 程序或历史版本归档。
